# KI-drevet utvikling

KI som kollega gjennom hele utviklingsløpet: fra work item i Azure DevOps til
brainstorm, spec og plan, implementasjon, pull request og merge. Arbeidsmåten er
kodet som skills i repoet — delt, versjonert og gjenbrukbar. Inkluderer DDD-vinkling
på hvor mennesket bør stå (core domain) og hvor agenten kan slippes løs, guardrails
rundt autonomi, tall fra 7 uker med reell bruk, og ærlige fallgruver.

`ai` `agents` `claude-code` `skills` `azure-devops` `ddd` `developer-experience`
> Duration: 30 min
