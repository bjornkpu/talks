## [Build Your Own Cloud](build-your-own-cloud/README.md)

Practical end-to-end tour of building and operating a cloud-native .NET 10 app with
Twelve-Factor principles, Docker, Kubernetes, cert-manager/Cloudflare/Let’s Encrypt,
and GitHub Actions CI/CD—showing unified Dev, Ops, and DevOps delivery.

`development` `operations` `devops` `docker` `kubernetes` `github`
> Duration: 30 min

## Prerequisites

- Basic Git and docker.
- Basic software development

## [Understanding GitHub](github-introduction/README.md)

Introduction to GitHub as a collaboration platform: contrasts Git vs. GitHub, explores
repositories, users, organizations, teams, projects, issues, Actions & Packages, and
briefly compares Azure DevOps for context—includes a live workflow demo.

`github` `git` `collaboration` `projects` `issues` `actions`
> Duration: 30 min

## Prerequisites

- Basic version control concepts (commits, branches)
- Optional: prior use of any Git hosting service

## [Hvorfor Platform Engineering](platform-engineering/README.md)

Skaler utviklingsorganisasjonen — ikke kompleksiteten. Introduksjon til Platform
Engineering og Internal Developer Platforms (IDPs): hvorfor golden paths og
selvbetjening gir utviklerverdi, hva det betyr for utviklere, ops og virksomheten,
og hvordan man starter med en Minimum Viable Platform.

`platform-engineering` `idp` `golden-paths` `developer-experience` `devops` `team-topologies`
> Duration: 30 min

## Prerequisites

- Basic understanding of cloud-native delivery (containers, CI/CD)
- Optional: familiarity with DevOps and Kubernetes concepts
