# Understanding GitHub

Introduction to GitHub as a collaboration and project management platform:
differentiates Git (distributed version control) from GitHub (workflow + collaboration),
covers core features (repositories, users, organizations, teams, projects, issues),
demonstrates planning and execution flows, and touches on Actions, Packages,
and Azure DevOps comparison.

`github` `git` `collaboration` `issues` `projects` `actions` `packages``version-control`
> Duration: 20 min

## Prerequisites

- Basic Git (clone, commit, push)
- Familiarity with branching and pull requests (helpful but not required)
